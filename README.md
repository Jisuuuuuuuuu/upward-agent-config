# Upward · 向上｜研究访谈 Agent 配置

本仓库对应课程提交第 4 部分（Progress data）的「配置内容」，同时提供「最终数据集」文件。它归档青少年脊柱侧弯研究访谈的规则、证据核验工具和模型微调样本。网页攀爬演示的源代码见 [Upward · 向上](https://github.com/Jisuuuuuuuuu/upward-rehab)。

## 文件索引

| 文件 | 内容与用途 |
| --- | --- |
| [Skill.zip](Skill.zip) | 原版研究访谈 Skill。解压后从 `SKILL.md` 开始阅读。 |
| [sft_dataset.json](sft_dataset.json) | UTF-8 结构化训练、验证和独立测试资料。共 589 条。 |
| [config.json](config.json) | 提交配置索引：标明 Skill 入口、规则资源、脚本、数据划分及所需材料。 |

## Skill

- `SKILL.md`：规定 Agent 身份、适用任务、访谈步骤、证据引用和回答边界。
- `assets/`：身份卡、访谈协议、来源清单、会话日志与证据台账模板、合成示例。
- `scripts/`：核验来源及证据索引、建立证据台账、验证会话记录。运行时采用 Python 3；读取 Excel 的脚本需要 `openpyxl`。各脚本可用 `--help` 查看参数。
- 来源核验和台账生成需要另行提供相应的原始文件或清洗证据索引。本仓库中的数据集是微调与评估资料，不能代替原始证据。

## 数据集

| 划分 | 条数 | 用途 |
| --- | ---: | --- |
| `splits.train` | 480 | 监督微调，供模型学习访谈回答方式。 |
| `splits.validation` | 79 | 调整训练配置与选择模型版本。 |
| `splits.test` | 30 | 独立评估题库，包含情境、提问、评估重点和评分规则。 |

训练与验证样本含 `instruction`、`input` 与 `output`，以及来源分组与证据编号。原始附件原样保留；这个仓库不登记云平台凭据，也不包含部署任务、模型权重或单独的检索服务配置。提交给老师时，请确认老师的 GitHub 账号拥有此私有仓库的访问权限。
